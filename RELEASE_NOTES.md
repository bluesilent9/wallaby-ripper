# Wallaby Ripper V1

First stable release for maintained Ubuntu and Kubuntu releases.

- A local browser interface with a Wallaby Wallet-style sidebar and one PDF destination.
- Select an ACSM file and click Start to receive an unencrypted PDF through the browser.
- Automatic discovery/reuse of existing authorization or creation of an anonymous Adobe ADEPT authorization.
- Progress through Key setup, Download, Decrypt, Verify and Ready.
- Immediate cleanup of the temporary encrypted PDF after successful validation.
- Installable architecture-independent DEB with bundled native sources built locally on first launch.
- Real PDF decryption verified in eight maintained Ubuntu userspaces, including Ubuntu Pro and Legacy releases.

Package version: 1.0.0. An account-bound ticket may require its original Adobe authorization. See README.md and VALIDATION.md for compatibility and test limits.
